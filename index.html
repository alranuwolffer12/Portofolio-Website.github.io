Tentang Saya
Saya adalah pelajar Rekayasa Perangkat Lunak yang memiliki ketertarikan pada pengembangan website, game, dan teknologi digital. Saya senang mempelajari bagaimana sebuah ide dapat diubah menjadi sebuah produk yang dapat digunakan dan dimainkan.

Dalam proses belajar, saya banyak mengeksplorasi berbagai teknologi seperti HTML, CSS, JavaScript, Godot, GDScript, Blender, dan Aseprite. Saya juga terbiasa menggunakan berbagai tools open-source untuk membantu proses pengembangan dan eksperimen saya.

Saat ini saya berfokus untuk terus membangun project pribadi dan memperluas pengalaman di bidang web development dan game development. Saya ingin menjadikan setiap project sebagai bagian dari perjalanan untuk berkembang menjadi developer yang lebih baik.
